# Project 8 – Flask Signup Website

## 1. What It Does

This is a simple Flask website with a signup page, a welcome page, and a search page.

Users can enter their name, email, and password. The website checks that all three fields are filled in before allowing signup. After successful signup, it displays a welcome message with the user's name.

The search page lets users enter a word and displays what they searched for.

## 2. What It's Built With

- Python
- Flask
- HTML
- CSS

## 3. How to Run It

1. Install Python 3.
2. Install Flask by running:

   `pip install flask`

3. Open the project folder in VS Code.
4. Open the terminal and run:

   `python3 app.py`

5. Open your browser and visit:

   `http://127.0.0.1:5000`
